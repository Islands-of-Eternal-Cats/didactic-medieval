## Why

Сейчас здания появляются мгновенно при клике — нет задержки, нет процесса строительства, игрок не наблюдает, как колонисты возводят постройки. Это лишает игру глубины и ощущения живого мира. Нужна система очереди строительства: игрок размещает стройплощадку, а колонисты автономно строят её в течение некоторого времени.

## What Changes

- Добавляется `ConstructionQueue` ресурс в ECS-ядро, управляющий активными стройками
- При клике в режиме строительства создаётся `ConstructionSite` вместо готового здания
- Колонисты автоматически берут стройки, перемещаются к ним и увеличивают прогресс
- По завершении стройплощадка заменяется готовым зданием
- Фронтенд рендерит стройплощадки с индикатором прогресса
- WASM API расширяется для передачи данных о стройках

## Capabilities

### New Capabilities
- `construction-queue`: Очередь строительства — колонисты автономно возводят здания, размещённые игроком (спецификация уже существует)

### Modified Capabilities

*None*

## Impact

- **crates/core/src/resources.rs**: добавить ресурс `ConstructionQueue`
- **crates/core/src/components.rs**: добавить компонент `ConstructionSite`
- **crates/core/src/systems.rs**: добавить система обработки билд-запросов, назначения строителей, аккумуляции прогресса
- **crates/core/src/events.rs**: (возможно) новые события или доработка `BuildRequest`
- **crates/core/src/world.rs**: расширить WASM-экспорт для данных о стройках
- **src/render/**: новый рендерер стройплощадок или доработка BuildingRenderer
- **src/**: мелкие доработки UI для отображения прогресса
