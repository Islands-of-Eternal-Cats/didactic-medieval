# Пиксель-арт графика: Retro 16-bit

## Обзор

Замена плоских цветных прямоугольников и точек на процедурно генерируемые пиксель-арт спрайты. Все спрайты рисуются кодом на фронтенде — без внешних изображений.

**Стиль:** Retro 16-bit — насыщенные цвета, пиксельные текстуры, лёгкий дизеринг.

## Архитектура

Рендеринг на фронтенде (TypeScript Canvas 2D). Rust/WASM продолжает отдавать только данные: tile map (что где стоит) и позиции юнитов.

```
Rust ECS → JSON (tile map, unit positions) → TypeScript → Canvas 2D с ImageData
```

Генерация спрайтов происходит один раз при инициализации (или при смене seed) и кэшируется в OffscreenCanvas/ImageData.

## Тайловая карта

### Размеры
- 25 × 19 тайлов, каждый 32×32 px
- Итого поле 800×608 px

### Walkable (проходимые) — трава с декорациями

**Базовый слой травы:**
- Основной цвет: `#3a7d32` (варьируется между 3-4 оттенками для разнообразия)
- Пиксельная текстура: случайные единичные пиксели темнее (`#2d5a27`) и светлее (`#4a8d3a`) поверх базового цвета
- Граница тайла: 1px `#2d5a27` со скруглением внутреннего угла
- 3-4 варианта текстуры, выбираются случайно по `(col + row * 7 + seed)` — одинаково между кадрами

**Декорации (на ~20% walkable тайлов):**
- Кусты: пиксельная группа 8×8–10×10, цвет `#2d6b2d` с более светлыми точками
- Цветы: пиксельные кластеры 6×6, красные (`#e94560`) или жёлтые (`#FFD700`)
- Тип и позиция декорации детерминированы (`(col, row, seed)`)

### Blocked (непроходимые) — скалы и вода

**Скалы (~60% blocked):**
- Базовый цвет: `#5a5a6e` с вариациями
- Текстура: случайные пиксели светлее (`#6a6a7e`) и темнее (`#4a4a5e`) — эффект гранита
- Трещины: линии толщиной 1px, цвет `#3a3a4e`, рисуются алгоритмически
- Граница: 1px `#3a3a4e`

**Вода (~40% blocked):**
- Базовый цвет: `#1a2a4e`
- Текстура: волны — горизонтальные линии ярче (`#2a4a6e`) с шагом 4px, смещаются по времени (анимация)
- Блики: единичные пиксели `#4a8aff`, позиция меняется по времени

## Юниты

### Спрайт рыцаря 16×16

Спрайт рисуется на отдельном OffscreenCanvas 16×16, затем рендерится в позиции юнита.

```
  ░░░██████░░░░    // верх шлема
  ░░██▓▓▓▓██░░    // шлем (цвет отряда)
  ░██▓▓▓▓▓▓██░    // шлем
  ░██▓▓▓▓▓▓██░    // забрало
  ░░██▓▓▓▓██░░    // шея
  ░░████████░░    // плечи
  ░██░░░░░░██░    // тело (серебристый доспех)
  ░██░░▒▒░░██░    // пояс
  ░░░██░░██░░░    // ноги
  ░░░██░░██░░░    // сапоги (коричневые)
```

**Цвета:**
- Цвет отряда (шлем): `unit_id % 6` — красный, синий, жёлтый, фиолетовый, зелёный, оранжевый
- Доспех: `#aaa` (серебристый)
- Сапоги: `#555` (коричневый)
- Контур: `#222`

**Масштабирование:** спрайт 16×16 рисуется в тайл 32×32 через `imageSmoothingEnabled = false`

### Анимация

- **Стоячие:** лёгкое покачивание — `offsetY = sin(time * 2) * 0.5`
- **Движение:** шаги — поза ног меняется между двумя кадрами (смещение ног на ±1px), переключение каждые ~0.3с
- Анимация считается в JS по `performance.now()`, данные от Rust не требуются

### Размещение на карте

- Юнит центрируется в своей позиции (сейчас центр тайла)
- Спрайт рисуется с `drawImage(spriteCanvas, x - 8, y - 16)` — центр по X, низ по Y

## Производительность

- Тайлы: генерируются в OffscreenCanvas 25×19 спрайтов 32×32 при инициализации
- Кадр: копирование предварительно отрендеренных тайлов из тайловой карты + отрисовка юнитов
- Нет перегенерации текстур каждый кадр
- До 50 спрайтов юнитов — бюджетно для Canvas 2D

## Данные из Rust (без изменений)

- `getTileMap()` — JSON с сеткой `G`/`B` (уже есть)
- `getUnitPositions()` — JSON с `[{id, x, y}]` (уже есть)
- `tick(deltaMs)` — системный тик (уже есть)
- Новые WASM методы не требуются

## Изменения в коде

### TypeScript (`src/`)

**Новый файл `src/pixelSprites.ts`:**
- Генерация текстур тайлов (трава, кусты, цветы, скалы, вода)
- Генерация спрайта рыцаря по цвету
- Кэширование сгенерированных спрайтов

**Новый файл `src/tileMapRenderer.ts`:**
- Предварительная отрисовка всех тайлов в OffscreenCanvas
- Метод `getTile(x, y)` — возвращает готовый Canvas-тайл

**Изменения в `src/UnitsCanvas.tsx`:**
- `drawTileMap` → использует предварительно отрендеренные тайлы
- `drawUnits` → рисует спрайты рыцарей вместо кругов
- Добавить анимацию покачивания/шагов

### Rust (`crates/core/`) — без изменений

## Границы

- Только 2D Canvas рендеринг, без WebGL
- Нет внешних спрайтов/атласов
- Нет новых WASM методов
- Размер поля 800×608 не меняется
